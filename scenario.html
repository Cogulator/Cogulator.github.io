What goes in a scenario file?

Use these five CSV columns. Give each task a unique name and match the .goms filenames you load. Times are non-negative seconds (decimals allowed).

unique_task_name,goms_file,start_type,reference_task,start_time_in_seconds
alert,Alert.goms,starting_at,,15
reply,Reply.goms,starting_after,alert finishes,2
monitor,Monitor.goms,starting_after,alert starts,0

starting_at sets a scenario offset; leave the reference blank. For starting_after, enter a task name followed by starts or finishes, exactly as in a Task. The seconds add a delay after that event. Thread names are assigned automatically.
